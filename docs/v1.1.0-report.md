# N1cePDF v1.1.0 — initial implementation report

Historical report for the initial OCR implementation. The raster reconstruction, visual font
matching and segmentation changes supersede its white-mask/export description; see ocr-quality.md.

## Analysis and technical plan

Initial Git state: clean `main`. Development branch: `feature/v1.1.0`.
Existing pikepdf document model, PDFium rendering and selection, ReportLab writer,
edit-layer objects, undo commands, background task runner and PySide6 panels were retained.
The implementation added local recognition first, OCR-specific text replacement, Qt controls,
automated coverage, then version/build metadata and documentation.

## Delivered

- Optional local Tesseract executable; English, Russian, Romanian and combined recognition.
- Current page, explicit page ranges, entire document and automatic textless-page mode.
- Mixed-page recognition filters native text, including forms, and existing edit objects.
- Unrotated PDF-space line coordinates with CropBox handling and bounded render size.
- Worker execution, queued progress, subprocess cancellation and timeout; no partial commits.
- Missing executable/language errors, stale-result rejection and one-step OCR undo/redo.
- Recognized lines appear with editor-only guide frames, use existing text/geometry panels,
  and can be moved, resized, copied, erased and searched.
- Unchanged OCR saves invisible searchable text; edits use white masks at fixed source bounds
  and visible replacement text. Original scan image data is preserved without rasterizing the page.
- OCR pages retain private edit state, allowing continued editing after reopen without
  accumulating text layers, ordinary added objects or annotations.
- Version 1.1.0 in application, project metadata, Windows build scripts, installer and resources.

## Executed verification

In an isolated `/tmp/n1cepdf-venv` environment on Linux (Python 3.14.3, Qt offscreen):

```sh
QT_QPA_PLATFORM=offscreen /tmp/n1cepdf-venv/bin/python -m pytest -q
# 157 passed in 17.49s

QT_QPA_PLATFORM=offscreen /tmp/n1cepdf-venv/bin/python main.py --self-test /tmp/n1cepdf-selftest-result.json
# exit 0; report ok=true, including opening and closing the Qt main window

python -m compileall -q n1cepdf tests
# exit 0

git diff --check
# exit 0
```

Coverage includes actual Tesseract images in all three languages, actual scanned multipage
PDFs, mixed/native/form text filtering, page rotation and crop coordinates, editing and saving,
reopening editable state, undo/redo, process cancellation/timeouts/errors, missing dependencies,
Qt selection/properties/move/resize/search/progress/cancel/error paths and existing regressions.
Unchanged OCR is pixel-identical when rendered; decoded source image bytes are preserved.
PDF stream compression may change losslessly during normal pikepdf saving.

No system packages were installed. The existing Tesseract installation and eng/rus/ron data
were used. Python dependencies were installed only in the isolated temporary environment.
No installer was built; no interactive Windows/Fedora desktop validation was performed.
No commit or push was made.

## Run

From this checkout using the prepared environment:

```sh
/tmp/n1cepdf-venv/bin/python main.py
```

For a permanent development environment, create a venv with Python 3.12+, activate it,
install `requirements/dev.txt`, then run `python main.py`.
Use Tools → «Распознать текст (OCR)…» or Ctrl+Shift+O, choose language and scope,
then use Edit Text (T) to select a recognized line and Properties to edit it.
Use Select (S) to move/resize. Save or Save As writes the resulting PDF.

Tesseract installation commands for Fedora/Debian and Windows PATH/environment setup
are documented in README.md. The Windows build remains `build-windows.bat`;
Tesseract and traineddata are external optional dependencies, not bundled downloads.

## Limits

White-mask editing cannot reconstruct photographs or patterned backgrounds and may hide details
inside the source rectangle. The UI warns before OCR. Original image content remains embedded;
this is not secure redaction. Recognition, font metrics and layout are approximate; handwriting,
skew, tables and vertical text can need preprocessing. Browse character selection operates on
original native PDF text; OCR editing uses the existing object tools. Page rendering cannot
be interrupted mid-render. Other editors can leave N1cePDF private edit state stale if they
modify the saved appearance; see docs/known-limitations.md. Windows installer and interactive
platform checks remain in docs/release-checklist.md.
